XMB Launcher turns your home screen into the PlayStation 3 menu: categories across, apps down, the slow glowing wave behind it all.

Install in a minute

  1. Tap Download for Android and save the zip.
  2. Open the zip in Files and tap app-release.apk.
  3. If Android asks, allow installs from this app, then tap Install.
  4. Press Home, pick XMB and choose Always.
