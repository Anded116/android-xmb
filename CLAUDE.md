# XMB-лаунчер — правила сессии

Домашний экран для Android в стиле крестового меню: разделы по горизонтали, приложения вниз. Две сборки —
`full` (личная, для Nothing Phone с кнопкой Essential) и `store` (для Google Play). Устройство и решения —
`README.md`, выпуск — `docs/play/`.

## Тикеты — обязательны

Файловый трекер: `node tools/tickets.mjs <команда>` (`tools/tickets.ps1` только вызывает его). Правила и поля —
`tickets/README.md`, рецепт — скилл `tickets`. Контекст сессии стирается, тикеты — нет.

- **Начало сессии** → `node tools/tickets.mjs list` и `tickets/BOARD.md`: что в работе, что решено.
  Решение автора не пересматривать без автора.
- Пакет просьб пользователя → по тикету на пункт, до начала работы.
- Пользователь принял решение в диалоге → `decision`-тикет `-Source user` в ту же сессию.
- Начал работу → `set -Status in-progress`; сделал → `fixed` + `-Commits`, в заметке — что попробовать.
- Баг вне скоупа или отложенная работа → тикет, а не TODO в чате.
- Конец сессии, если тикеты трогались → `board` + `validate` (`OK`), коммитить вместе с кодом.
- `verified` агент не ставит сам — только по словам автора.

## Сборка и проверка

- `powershell -File build.ps1 [-Install] [-Flavor full|store] [-Bundle] [-Serial ...]`. Свои пути — в `local.ps1`
  (не в git). SDK 36 — в `.tools/sdk` проекта.
- Gradle с новыми зависимостями и `sdkmanager` запускать **через PowerShell**: из Bash сеть до Google Maven
  не ходит, а запись в чужие каталоги тихо не проходит.
- Телефон: новую сборку ставить сразу (`-Install`), без вопроса. **Никогда не `am force-stop dev.anded.xmb`** —
  Android сбросит живые обои и выключит службу кнопки Essential. Системные настройки телефона не менять
  (`wm size`, язык системы) — другие экраны проверять на своём AVD `xmb` (порт 5556), язык — `cmd locale
  set-app-locales`.
- Не нажимать в лаунчере то, что откроет чужие приложения автора, без нужды.
- Музыка с плеера HiBy (прошивка r3ii-xmb): `python tools/hiby_import.py --card <диск>` — треки в Music/HiBy, оценки
  и плейлисты в данные лаунчера; повторный запуск докладывает только новое и данные телефона не затирает.

## Публичность

Репозиторий пока публичный (станет закрытым): ничего личного — ни серийника телефона, ни локальных путей,
ни почты, ни перечня приложений автора; личные значки — только в `app/src/full`. Коммиты — локально, пуш только
по просьбе.
